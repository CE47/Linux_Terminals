1. **`ls`** — Visually teach directory listing, hidden files, and file types.
2. **`pwd`** — Show exactly where the user currently is in the filesystem.
3. **`cat`** — Display file contents while reinforcing paths and file reading.
4. **`mkdir`** — Let users create directories and watch the filesystem map update.
5. **`cp`** — Demonstrate copying files with clear source-to-destination animation.
6. **`mv`** — Teach moving and renaming through visible filesystem changes.
7. **`rm`** — Explain deletion safely using a reversible, visual model.
8. **`find`** — Search an entire directory tree using names, types, and patterns.
9. **`sed`** — Show find-and-replace transformations with before-and-after output.
10. **`cut`** — Teach extracting specific columns from structured text.
11. **`head` / `tail`** — Demonstrate viewing the beginning or end of files and command output.
12. **`wc`** — Visually count lines, words, and characters.
13. **`sort` / `uniq`** — Organize results and identify duplicate entries.
14. **`chmod`** — Teach user, group, and other permissions through an interactive permission matrix.
15. **Pipes and redirection** — Cover `|`, `>`, and `>>` by connecting commands and visually routing their output.
